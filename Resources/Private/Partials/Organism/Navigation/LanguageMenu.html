Language menu organism — renders enabled site languages as a link list. Arguments: languages {array} — LanguageMenuProcessor result (dataProcessing.25 in page.typoscript). Each item has: label, url, isCurrent, languageUid, hreflang, locale, navigationTitle, title, flag, direction. label {string} — Accessible aria-label for the
landmark. Defaults to "Sprache wählen" / "Select language". Usage example (in template):
  • {language.label}
