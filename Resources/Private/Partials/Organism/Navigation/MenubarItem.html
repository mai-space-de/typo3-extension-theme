Menubar item — renders a single menu entry at any nesting depth. Called recursively: sub-menus call this partial for their own children. Arguments: item {array} — single MenuProcessor item with keys: title, link, target, active, current, hasSubpages (bool), children (array) depth {integer} — current nesting depth (0 = menubar level, 1 = first dropdown, 2 = fly-out) ARIA roles per depth: depth 0 → role="menuitem" on (direct child of menubar) depth ≥1 → role="menuitem" on (child of role="menu") The wrapping
  • always carries role="none" (presentational). Sub-menu trigger arrows: depth 0 → SVG pointing down (class="down") depth ≥1 → SVG pointing right (class="right")
  • ── Link / trigger ───────────────────────────────────────────────── {item.title} ── Sub-menu indicator arrow ────────────────────────────────── ── Sub-menu (recursive) ───────────────────────────────────────────
