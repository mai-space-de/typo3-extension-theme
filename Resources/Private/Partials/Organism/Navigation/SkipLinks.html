Skip links — first focusable element on the page so keyboard and screen-reader users can bypass the header/navigation and jump straight to the main content (and, when present, to the primary navigation). Accessibility notes: - Visually hidden by default; becomes visible on :focus / :focus-visible via the .mai-skip-link styles in menubar-navigation.scss. - Targets must exist on the page: #main — the
landmark in Templates/Page/Default.html #main-nav — the
in Menubar.html Arguments: mainLabel {string} — link text for the "skip to content" link (default: "Zum Inhalt springen"). navLabel {string} — link text for the "skip to navigation" link (default: "Zur Navigation springen").
