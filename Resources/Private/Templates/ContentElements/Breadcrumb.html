Breadcrumb navigation content element. Data source: tt_content.maispace_breadcrumb.dataProcessing.90 (MenuProcessor, special = rootline) injects `{breadcrumbItems}` — an array of page items from the site root down to the current page. Each item carries: title {string} — nav_title ?? title link {string} — full URL of the page active {bool} — 1 when this page or a descendant is active current {bool} — 1 only for the current (deepest) page Semantics (PLANNED_ELEMENTS_IMPLEMENTATION.md §5):
→

    is only rendered when the rootline returns at least one item. An empty breadcrumb (e.g. root page itself) renders nothing rather than an empty landmark.
