PKG: Prefix Example Template This template demonstrates the new PKG: prefix for system resources. PKG: is the modern alternative to EXT: for package resources in TYPO3 v14. Syntax: PKG:vendor/package-name:path/within/package Examples: - PKG:maispace/mai-theme:Resources/Public/Scss/main.scss - PKG:maispace/mai-assets:Resources/Public/JavaScript/app.js - PKG:maispace/mai-theme:Resources/Public/Icons/logo.svg Benefits: - Unified resource API (PKG:, FAL:, URI:) - Better caching and performance - Consistent with modern TYPO3 architecture - Backward compatible with EXT: (both work) Using PKG: prefix for CSS/SCSS files Note: EXT: still works, but PKG: is the recommended approach Using PKG: prefix for JavaScript files Using PKG: prefix for SVG icons Traditional EXT: syntax (still supported) Modern PKG: syntax (recommended)
