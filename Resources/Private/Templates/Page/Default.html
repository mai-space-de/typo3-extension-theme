Main page template. - `HeadAssets` emits :root { --mai-* } CSS variables + font preload hints. - `Main` renders the semantic page shell with colPos landmarks. Webfont — Source Sans 3 (body/headings) + Source Serif 4 (pull-quotes). Loaded before the stylesheet so font-display=swap avoids invisible text. Critical CSS — inline :root custom properties generated from EXT:mai_theme/Configuration/Sets/MaiTheme/settings.definitions.yaml and piped through `lib.themeVars` in setup.typoscript. Declarations here are outside any @layer, so they override the layered defaults in _variables.scss.
