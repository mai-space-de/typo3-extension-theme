# Handbuch: Theme

Seiten baust du aus den Theme-Elementen. Bilder gehören in das dafür vorgesehene Feld des Elements, sonst bleibt die Medienfläche leer.

## Gruppen

| Gruppe | Beispiele |
|---|---|
| Basis | Text, Überschrift, Bild, Video, Button, Trenner |
| Seite | Hero, Banner, Call-to-Action, Unterseiten |
| Bausteine | Karte, Teaser, Zitat, Kontakt, Statistik |
| Widgets | Akkordeon, Slider, Tabs, Timeline, Vorher/Nachher |
| Formulare | Formular, Newsletter, Karte |
| Daten | Tabelle, Galerie, Dateiliste, Diagramm |

Icons wählst du aus dem Icon-Katalog des Elements, nicht als hochgeladenes SVG.

## Vorschau

Die Look-Vorschau zeigt das Inhaltselement in einem eigenen Rahmen. Dafür liefert das Theme die Vorschau-Templates. Styles und Skripte müssen dabei ohne Integritätsprüfung geladen werden, sonst bleibt der Rahmen ungestylt.
